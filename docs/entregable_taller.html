1. Resumen y Objetivos del Proyecto

El objetivo de este proyecto es el desarrollo de una aplicación móvil en Flutter que consume datos públicos de la República de Colombia a través de API Colombia. La aplicación implementa navegación declarativa mediante go_router, arquitectura por capas (configuración, modelos, servicios, temas, vistas y widgets), manejo de estados de ciclo de vida de peticiones (Cargando, Éxito, Error con reintento, y Búsqueda vacía), variables de entorno (.env) y un flujo de trabajo bajo GitFlow.

2. Endpoints Implementados (4 Mínimos Requeridos)

Endpoint Ruta API Base Ruta API Detalle Descripción y Datos Destacados
1. Departamentos /api/v1/Department /api/v1/Department/{id} División político-administrativa: capitales, población, superficie, municipios y prefijo telefónico.
2. Atracciones Turísticas /api/v1/TouristicAttraction /api/v1/TouristicAttraction/{id} Patrimonio nacional: parques, reservas, museos, galería de imágenes y coordenadas GPS.
3. Presidentes /api/v1/President /api/v1/President/{id} Mandatarios de la República: periodos presidenciales, partidos políticos, retratos y biografías.
4. Platos Típicos /api/v1/TypicalDish /api/v1/TypicalDish/{id} Gastronomía colombiana: imágenes, ingredientes principales y departamento de procedencia.

3. Estructura y Arquitectura del Código

lib/config/
Gestión de variables de entorno mediante Environment y flutter_dotenv (URL base, timeouts, nombres).
lib/models/
Modelos de datos fuertemente tipados con métodos serializadores fromJson y toJson para cada entidad y sus submodelos.
lib/services/
Cliente HTTP centralizado ApiColombiaService con manejo de ApiException, validación de códigos de estado HTTP (200, 404, 500), timeouts y decodificación UTF-8.
lib/routes/
Configuración de rutas con GoRouter, subrutas para maestro-detalle, paso de parámetros de ruta (:id) y objetos por extra.
lib/themes/
Diseño visual moderno en Material 3 con esquemas claro y oscuro basados en la identidad visual de Colombia.
lib/views/
Pantallas principales: DashboardView, vistas de listado con filtrado en tiempo real y vistas de detalle exhaustivas.
lib/widgets/
Componentes modulares reutilizables: LoadingView, ErrorView, EmptyView, CustomSearchBar, ImageWithFallback, InfoChip y DashboardCard.

4. Paquetes Implementados

  • http (v1.6.0): Peticiones cliente-servidor a API Colombia.
  • go_router (v18.1.1): Enrutamiento declarativo y navegación maestro-detalle.
  • flutter_dotenv (v6.0.1): Carga segura de variables de configuración.
  • intl (v0.20.3): Formateo de fechas y números.
